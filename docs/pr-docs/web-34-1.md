# [web-34-1] 관리자 모집 공고 수정 API 구현

## 작업 내용
관리자 페이지에서 모집 공고 정보를 수정할 수 있는 API를 구현합니다.

## 변경 사항
- `PATCH /api/v1/admin/recruitment` 엔드포인트 구현
- `RecruitmentUpdateRequestDto` 추가 (`field`, `target`, 날짜 필드)
- `AdminRecruitmentService.update()` 구현
- 시작일/종료일 유효성 검증 (모집 기간, 면접 기간 각각 독립 검증)

## API

### 모집 공고 수정
`PATCH /api/v1/admin/recruitment`

**Request:**
```json
{
  "target": "대학교 1~3학년",
  "field": "프론트엔드, 백엔드",
  "recruitmentStart": "2026-05-01",
  "recruitmentEnd": "2026-05-31",
  "interviewStart": "2026-06-01",
  "interviewEnd": "2026-06-15",
  "notificationDate": "2026-06-20"
}
```

**Response:** `200 OK`
```json
{
  "success": true,
  "data": {
    "target": "대학교 1~3학년",
    "field": "프론트엔드, 백엔드",
    "recruitmentStart": "2026-05-01",
    "recruitmentEnd": "2026-05-31",
    "interviewStart": "2026-06-01",
    "interviewEnd": "2026-06-15",
    "notificationDate": "2026-06-20",
    "recruiting": true
  }
}
```

## 테스트
- [x] PATCH /api/v1/admin/recruitment → 200 OK
- [x] 시작일 > 종료일 시 400 INVALID_INPUT
- [x] 모집 기간/면접 기간 독립 검증
