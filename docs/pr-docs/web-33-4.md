# [web-33-4] 관리자 프로젝트 생성 API 구현

## 작업 내용
관리자 페이지에서 메인 페이지 프로젝트 행사를 새로 추가할 수 있는 API를 구현합니다.
사진 파일을 직접 업로드하면 MinIO에 저장 후 URL이 반환됩니다.

## 변경 사항
- `POST /api/v1/admin/project` 엔드포인트 구현 (multipart/form-data)
- `ProjectSaveRequestDto` 추가 (사진은 별도 파트로 전송)
- `AdminProjectService.save()` 구현
  - `MainPageConfig` 싱글톤(ID=1) 연결
  - 우선순위는 `Integer.parseInt(year)` 기반 부여 → 연도 오름차순(2023 → 2024 → 2025) 자동 정렬
  - 엔티티 저장 후 사진 파일을 MinIO에 업로드

## API

### 프로젝트 생성
`POST /api/v1/admin/project`

> Content-Type: `multipart/form-data`
>
> `request` 파트는 반드시 `Content-Type: application/json`으로 명시해야 합니다.

**Request Parts:**

| 파트 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `request` | JSON | ✅ | 프로젝트 정보 |
| `photos` | 파일(이미지) | ❌ | 사진 최대 3개 (선택, 이미지만 허용) |

**request (JSON):**
```json
{
  "year": "2025",
  "projectName": "ONE 웹사이트",
  "award": "최우수상",
  "activity": "2025 동계 MT · 정기 세미나 및 튜터링 운영",
  "startDate": "2025-03-01",
  "endDate": "2025-11-30",
  "participantCount": 8,
  "techStacks": ["Spring Boot", "React", "MySQL"],
  "description": "동아리 공식 웹사이트"
}
```

**Response:** `201 Created`
```json
{
  "success": true,
  "data": {
    "projectId": 2,
    "year": "2025",
    "projectName": "ONE 웹사이트",
    "award": "최우수상",
    "activity": "2025 동계 MT · 정기 세미나 및 튜터링 운영",
    "startDate": "2025-03-01",
    "endDate": "2025-11-30",
    "participantCount": 8,
    "techStacks": ["Spring Boot", "React", "MySQL"],
    "description": "동아리 공식 웹사이트",
    "photos": [
      { "id": 1, "url": "https://cdn.example.com/projects/photo1.jpg" }
    ]
  }
}
```

**프론트엔드 요청 예시 (JavaScript):**
```javascript
const formData = new FormData();
formData.append('request', new Blob([JSON.stringify({
  year: "2025",
  projectName: "ONE 웹사이트",
  award: "최우수상",
  activity: "2025 동계 MT · 정기 세미나 및 튜터링 운영",
  techStacks: ["Spring Boot", "React"],
  startDate: "2025-03-01",
  endDate: "2025-11-30",
  participantCount: 8
})], { type: 'application/json' }));

photoFiles.forEach(file => formData.append('photos', file));
```
