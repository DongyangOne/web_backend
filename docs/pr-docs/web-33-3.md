# [web-33-3] 관리자 프로젝트 수정 API 구현

## 작업 내용
관리자 페이지에서 메인 페이지 프로젝트 행사 정보를 수정할 수 있는 API를 구현합니다.
사진은 `keepPhotoIds`(유지할 기존 사진 ID)와 `newPhotos`(신규 파일)로 개별 관리합니다.

## 변경 사항
- `V5__update_project_event.sql`: `project_event` 테이블에 `year`, `award`, `activity`, `start_date`, `end_date` 컬럼 추가, `project_name` TEXT 변경, `project_tech_stack` 테이블 신규 생성
- `ProjectEvent` 엔티티: `year`, `award`, `activity`, `startDate`, `endDate` 필드 추가, `techStacks` OneToMany 관계 추가 (CascadeType.ALL, orphanRemoval)
- `ProjectTechStack` 엔티티 신규 생성
- `ProjectTechStackRepository` 추가
- `ProjectDetailResponseDto` 추가 (`photos` 필드: `id` + `url` 포함)
- `ProjectPhotoResponseDto` 추가
- `ProjectUpdateRequestDto` 추가 (`keepPhotoIds` 포함)
- `MinioService`: `uploadFile()`, `deleteFile()`, `extractObjectKey()` 추가
- `AdminProjectService` 추가 (`update`)
- `AdminProjectController` 추가

## API

### 프로젝트 수정
`PATCH /api/v1/admin/project/{projectId}`

> Content-Type: `multipart/form-data`
>
> `request` 파트는 반드시 `Content-Type: application/json`으로 명시해야 합니다.

**Request Parts:**

| 파트 | 타입 | 필수 | 설명 |
|------|------|------|------|
| `request` | JSON | ✅ | 프로젝트 정보 + keepPhotoIds |
| `newPhotos` | 파일(이미지) | ❌ | 새로 추가할 사진 (선택, 이미지만 허용) |

**request (JSON):**
```json
{
  "year": "2025",
  "projectName": "ONE 웹사이트",
  "award": "최우수상",
  "activity": "2025 동계 MT · 정기 세미나 및 튜터링 운영",
  "startDate": "2025-03-01",
  "endDate": "2025-11-30",
  "participantCount": 8,
  "techStacks": ["Spring Boot", "React", "MySQL"],
  "description": "동아리 공식 웹사이트",
  "keepPhotoIds": [1, 3]
}
```

> `keepPhotoIds`: 유지할 기존 사진 ID 목록. 생략하거나 빈 배열이면 기존 사진 전체 삭제.
> 최종 사진 수 = `keepPhotoIds.size()` + `newPhotos.size()`, 최대 3개 (0개 허용)

**Response:** `200 OK`
```json
{
  "success": true,
  "data": {
    "projectId": 1,
    "year": "2025",
    "projectName": "ONE 웹사이트",
    "award": "최우수상",
    "activity": "2025 동계 MT · 정기 세미나 및 튜터링 운영",
    "startDate": "2025-03-01",
    "endDate": "2025-11-30",
    "participantCount": 8,
    "techStacks": ["Spring Boot", "React", "MySQL"],
    "description": "동아리 공식 웹사이트",
    "photos": [
      { "id": 1, "url": "https://cdn.example.com/projects/photo1.jpg" },
      { "id": 3, "url": "https://cdn.example.com/projects/photo3.jpg" },
      { "id": 5, "url": "https://cdn.example.com/projects/photo5.jpg" }
    ]
  }
}
```

**프론트엔드 요청 예시 (JavaScript):**
```javascript
const formData = new FormData();
formData.append('request', new Blob([JSON.stringify({
  year: "2025",
  projectName: "ONE 웹사이트",
  award: "최우수상",
  activity: "2025 동계 MT · 정기 세미나 및 튜터링 운영",
  techStacks: ["Spring Boot", "React"],
  keepPhotoIds: [1, 3],
  startDate: "2025-03-01",
  endDate: "2025-11-30",
  participantCount: 8
})], { type: 'application/json' }));

// 새 사진이 있을 때만 추가 (없으면 파트 생략)
newPhotoFiles.forEach(file => formData.append('newPhotos', file));

axios.patch(`/api/v1/admin/project/${projectId}`, formData);
```
